## ✨ 功能

- 👆 點一下原文中有底線的字詞，從下方浮出註釋
- 🔍 搜尋詩題、作者、朝代、體裁、出處、主題或詩句
- 🗂️ 依朝代、體裁、作者／出處、閱讀紀錄（書籤、已讀、未讀）篩選，可以同時套用；選項旁標出符合的篇數
- 🔖 書籤與已讀：閱讀頁右下角的閱讀工具按鈕「⋯」展開書籤、已讀、語譯三個按鈕；目錄卡片上標出記號，最下方顯示已讀篇數
- 📄 目錄每頁 10 篇，以頁碼切換
- 🔠 閱讀設定：拖拉調整原文字級（題目大小固定）、原文橫排／直排切換
- 📖 原文下附語譯：每句原文下方直接顯示語譯（散文也逐句對照），字詞仍可點開看註釋
- 🈯 語譯開關：右下角展開後的「譯」按鈕可隨時顯示或隱藏語譯，選擇會記住；展開或收起也會記住
- 📜 版本與參考資料：說明原文依據的版本、列出各版本的不同寫法，並附上每篇依據的文獻
- 🔤 繁體／简体切換：簡體版的讀音以拼音標示；註釋中說明版本差異的寫法保留繁體，才看得出各版本的不同；切換時不重新載入，停在原來讀到的地方

## 🛠️ 開發

純前端、零依賴、零建置步驟。專案分成兩部分：

- `public/`：網站本體，**只有這個資料夾會部署**到 GitHub Pages。網站是純靜態的，沒有任何可以修改資料的功能。
- `editor/` 與 `scripts/`：網頁編輯器和工具，**只在自己的電腦上使用**，不會部署。

| 檔案 | 用途 |
|---|---|
| `public/index.html` | 頁面結構：頂部列、設定面板、註釋面板 |

| `public/js/app.js` | 畫面流程：路由、目錄搜尋、閱讀頁、註釋、閱讀設定 |

| `public/js/hans-ui.js` | 簡體模式的介面文字對照表（自動產生，不要手動修改） |
| `public/js/terms.js` | 目錄排序用的朝代、體裁清單（由 `make_hans.py` 依 `scripts/poemdata.py` 自動產生，不要手動修改） |
| `public/sw.js` | Service Worker 離線快取 |
| `public/manifest.json` | PWA 設定 |
| `public/icons/` | App 圖示：iPhone 用 180、其他系統用 192／512（已裁圓角）、Android 自適應圖示用 maskable 512 |
| `editor/` | 網頁編輯器（本機使用，不部署） |

<summary>🖊️ 網頁編輯器（新增、修改、刪除作品）</summary>

在自己的電腦上執行：


- **說明**：右上角「？ 使用說明」逐一解釋每個按鈕與欄位，第一次打開時會自動顯示；滑鼠移到任何按鈕上也會出現簡短說明。
- **左邊**：作品清單，可搜尋。點作品就能編輯，「＋ 新增作品」開始新的一篇。

  - 「快速貼上整篇」：貼上整篇原文和整篇語譯，會依句號、問號、驚嘆號自動切句配對，再到表格裡微調。
  - 註釋：每一則旁邊即時顯示「找到」「只在題目」「找不到」「未填解釋」等狀態，判斷規則和「檢查」、`validate_poems.py` 相同。
- **下方**：
  - 「檢查」：列出錯誤與提醒。
  - 「儲存」：沒有錯誤才會寫入，寫入前把原資料備份到 `.backup/`。
  - 「預覽」：在網站中打開這篇。
  - 「匯出稿件」：存成文字檔。
  - 「刪除作品」：刪除這篇。如果這位作者已經沒有其他作品，作者資料會一併移除。

<details>
<summary>📝 用文字稿件或 JSON 新增作品</summary>

所有內容都在 `public/data/poems.json`。除了網頁編輯器，也可以用**純文字稿件**新增，不必直接編輯 JSON。

**用稿件新增**

1. 複製 [`templates/作品稿件範本.txt`](templates/作品稿件範本.txt)，改名為作品名稱，照範本填寫。原文一行，下一行用「譯：」寫語譯：
   ```text
   代號：loushiming
   標題：陋室銘
   作者代號：liuyuxi
   作者：劉禹錫
   朝代：唐
   生卒年：772–842
   類型：散文
   體裁：雜記
   主題：品德、隱逸

   【作者介紹】
   ……

   【原文與語譯】
   山不在高，有仙則名。
   譯：山不在於高，有了仙人就出名。

   【註釋】
   陋室：簡陋的屋子。
   斯｜斯是陋室：這。

   【創作背景】
   ……

   【版本】
   ……

   【賞析】
   ……

   【參考資料】
   《全唐文》卷六百八
   ```
2. 檢查稿件（不會修改資料）：
   ```bash
   python -I scripts/add_poem.py check 陋室銘.txt
   ```
3. 沒有錯誤後加入，工具會自動放在同朝代作品的後面，並把原資料備份到 `.backup/`：
   ```bash
   python -I scripts/add_poem.py add 陋室銘.txt
   ```
4. 依下方「發布新版本」更新快取版本。

**修改現有作品**：先匯出成稿件，編輯後加上 `--replace` 寫回。

```bash
python -I scripts/add_poem.py export loushiming 陋室銘.txt
python -I scripts/add_poem.py add 陋室銘.txt --replace
```

稿件的寫法：
- 幾行原文共用一句語譯時，把那幾行原文連續寫，最後再寫「譯：」。
- 詩詞的連續幾行會保留分行，例如律詩一聯寫成兩行；散文的連續幾行會接成同一句。所以散文的句子裡如果有換行（例如〈滕王閣序〉序末的詩），稿件保留不了，這類作品請用網頁編輯器修改。
- 空一行代表換段：散文的自然段，或詩詞的換章、換片。
- 註釋一行一則，寫成「詞：解釋」。同一個詞出現多次時，寫成「詞｜所在的原文片段：解釋」。
- 【版本】與【參考資料】可以省略。【版本】可以分段；【參考資料】一行一筆。

**直接編輯 JSON**

稿件會轉成下面的格式；也可以直接編輯 `public/data/poems.json`，改完執行 `python -I scripts/validate_poems.py check public/data/poems.json` 確認「錯誤數 0」，再執行 `python -I scripts/make_hans.py` 更新簡體版。

```jsonc
{
  "authors": {
    "sushi": { "name": "蘇軾", "dynasty": "宋", "years": "1037–1101", "intro": "作者介紹" },
    "liji": { "name": "《禮記》", "dynasty": "先秦", "years": "戰國至西漢", "intro": "出處介紹", "kind": "source" }
  },
  "poems": [
    {
      "id": "shuidiaogetou-mingyuejishiyou",  // 網址用的代號：英文小寫、數字與 -，全站唯一
      "title": "水調歌頭・明月幾時有",          // 詞牌與題目之間用「・」，閱讀頁會分兩行顯示
      "author": "sushi",                      // 對應 authors 的代號
      "source": "《東坡樂府》",                 // 選自哪本書／哪一篇（選填）
      "type": "verse",                        // verse：詩、詞、曲；prose：散文
      "form": "詞",
      "tags": ["思親", "哲理"],
      "preface": ["丙辰中秋，歡飲達旦……", "丙辰年中秋節，我……"],   // 小序：[原文, 語譯]（選填）
      "body": [
        [                                                              // 第一段（詩詞為一章或一片）
          // 詩句中的 \n 是換行，例如律詩一聯：["城闕輔三秦，\n風煙望五津。", "語譯"]
          ["明月幾時有？把酒問青天。", "明月是從什麼時候開始有的呢？我端起酒杯向青天發問。"],
          ["不知天上宮闕，今夕是何年？", "不知道天上的宮殿裡，今晚是哪一年？"]
        ],
        [                                                              // 第二段（下片）
          ["轉朱閣，低綺戶，照無眠。", "月光轉過朱紅色的樓閣……"]
        ]
      ],
      "notes": [
        { "term": "宮闕", "note": "宮殿。闕：讀作ㄑㄩㄝˋ……" },
        { "term": "何事", "in": "何事長向別時圓", "note": "為什麼。" }
      ],
      "background": "創作背景",                 // 字串，或分段的陣列
      "analysis": ["賞析第一段", "賞析第二段", "賞析第三段"],
      "edition": ["原文依……", "另比對……"],   // 選填：原文依據的版本與比對過的版本，分段的陣列
      "references": ["朱熹《詩集傳》卷二", "《新唐書》卷二百二〈文藝傳中・李白〉"]   // 選填：依據的文獻，一行一筆
    }
  ]
}
```

**`body` 怎麼填**
- 外層一筆是一段：散文的自然段，或詩詞的一章、一片。段與段之間在閱讀頁會有較大的間隔，散文每段第一句會空兩字。
- 內層每一筆是 `["原文", "語譯"]`：
  - 詩詞通常一句一筆，例如律詩一聯、詞的一句。
  - 散文也是一句一筆。
  - 幾句原文共用一句語譯時，就把那幾句原文寫在同一筆裡。
- 原文照錄、標點用全形。詩詞一筆裡要分行時（例如律詩一聯的上下句）用 `\n` 隔開，閱讀頁會照這個分行；太長的句子在手機上也會自動在標點後換行。

**其他欄位**
- `dynasty`：只能用 先秦、秦、漢、三國、魏晉、南北朝、隋、唐、五代、宋、元、明、清、臺灣；目錄依這個順序排列。
- `form`：只能用 四言詩、樂府詩、五言古詩、七言古詩、雜言古詩、五言絕句、七言絕句、五言律詩、七言律詩、詞、散曲、雜劇、史傳、論說、奏議、雜記、辭賦、序跋、小說。
- `notes` 註釋：
  - `term` 必須是原文或題目中一字不差的詞。
  - 每則只在第一次出現的位置標底線。
  - 同一個詞出現多次、或是「之」「其」這類常見字，用 `in` 指定一段包含它的原文片段（必須在全文中唯一）。
  - 只出現在題目中的詞（例如「早發白帝城」的「發」）會標在標題上。
- 原文以維基文庫為準，字形用教育部標準字。原文依據的版本寫在 `edition`；各版本的不同寫法寫在對應的註釋中，接在字義後面，例如「版本：本站依《甲書》卷幾作『某』；《乙書》卷幾作『某』。」
