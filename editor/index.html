使用說明

基本流程

  1. 按左邊清單的作品來修改，或按右上角「＋ 新增作品」。
  2. 填寫表單。原文與語譯可以一句一句輸入，也可以用「快速貼上整篇」。
  3. 按右下角「檢查」看有沒有錯誤，沒問題就按「儲存」。
  4. 按「預覽」到網站確認效果。
  5. 要發布到網站時：把 public/sw.js 開頭的 VERSION 版本號往上加，再推上 GitHub。

編輯器只在這臺電腦上運作，別人無法使用。每次儲存、刪除或調整順序前，原本的資料都會備份到專案的 .backup/ 資料夾。

開啟網站
在新分頁打開網站，看到的是已儲存的內容。

左邊：作品清單

搜尋框
輸入標題、作者或代號篩選清單。
點作品
載入到右邊表單修改。目前編輯中的作品會以紅色標示。
↕ 調整順序
進入排序模式：拖曳作品左邊的 ⠿，或按 ↑ ↓ 移動一格。只能在同一朝代內移動（網站一律先依朝代排列）。調好按「儲存順序」，不要的話按「取消」。網站的目錄和「上一篇／下一篇」都照這個順序。

基本資料

標題
詞、曲寫成「詞牌・題目」，例如「念奴嬌・赤壁懷古」，網站會分兩行顯示。
代號
網址用的英文，例如 loushiming。只能用小寫英文、數字和 -，不能和其他作品重複。建議用標題的拼音。
類型
「詩詞」或「散文」，決定網站上的排版（散文每段空兩字）。
體裁、主題、出處
主題 2–3 個，用頓號分隔；出處可以不填。

作者

選擇作者
已收錄的作者直接從選單挑選。選「＋ 新增作者…」可以新增。
作者代號
名字的拼音，例如 liuyuxi。新增時填寫，建立後就不能改。
修改作者資料
名稱、朝代、生卒年、介紹都能改，但會套用到這位作者的所有作品。
這是一部書
例如《禮記》《詩經》這類沒有單一作者的作品，打勾後網站會顯示「出處」。

小序

詞或詩前面的小序。打勾「有小序」後填寫原文與語譯。

原文與語譯

每一列
左邊原文、右邊語譯，一列一句。幾句原文共用一句語譯時，把它們寫在同一列。詩詞在原文欄按 Enter 可以分行，例如律詩一聯寫成兩行。
每一張卡片
一段：散文的自然段，或詩詞的一章、一片。網站上段與段之間會空開。
↑ ↓
把這一句往上或往下移。
＋
在這一句下面插入一個空白句。
✕
刪除這一句。
卡片右上「↑ 上移」「↓ 下移」「✕ 刪除段落」
移動或刪除整段。
＋ 新增一句
在這一段的最後加一句。
＋ 新增一段
在全文最後加一段。
快速貼上整篇…
把整篇原文、整篇語譯分別貼進兩個框，會依句號、問號、驚嘆號自動切句並配對；空一行代表換段。視窗會顯示兩邊的句數，套用後再到表格裡微調。注意：會取代目前的原文與語譯。

註釋

詞
要註解的詞，必須和原文一字不差。
前後文（選填）
同一個詞在原文出現好幾次時，網站預設把底線標在第一次出現的地方。要標在別處，就在這裡填一小段包含它的原文，例如註「之」時填「師者，所以傳道」。這段文字在全文中只能出現一次。
狀態標籤
找到 會在原文標底線； 只在題目 會標在標題上； 出現多次 建議填前後文； 找不到 請檢查用字。滑鼠移到標籤上可以看詳細說明。
↑ ✕
往上移、刪除這則註釋。註釋建議依原文出現的順序排列。

創作背景、版本、賞析、參考資料

創作背景、賞析
空一行代表分段。賞析建議 4–6 段。
版本（選填）
寫原文依據的版本，以及比對過的版本與差異概述，空一行分段。各版本的不同寫法，逐處寫在對應的註釋中，例如「版本：本站依《甲書》卷幾作『某』；《乙書》卷幾作『某』。」
參考資料（選填）
實際查閱並用到的文獻，一行一筆，例如「朱熹《詩集傳》卷二」。

下方按鈕

檢查
只檢查不儲存，在左下方列出錯誤（紅色，必須修正）與提醒（橘色，可以不改）。
儲存
沒有錯誤才會寫入資料，寫入前自動備份。
預覽
在網站中打開這一篇，看的是已儲存的內容，所以請先儲存。
匯出稿件
把這一篇轉成文字稿件，可以複製或下載保存，之後也能用「匯入稿件」貼回來。
刪除作品
刪除這一篇（會先確認並備份）。如果這位作者已經沒有其他作品，作者資料也會一併移除。

小提示

  • 滑鼠移到任何按鈕上，都會出現簡短說明。
  • 還沒儲存就切換作品或關閉頁面時，會先詢問。
  • 每次儲存、刪除或調整順序後，會自動更新網站的簡體版資料（需要先安裝 OpenCC：pip install opencc-python-reimplemented；沒有安裝時，執行編輯器的視窗會出現提醒）。
  • 不小心存錯了，可以從 .backup/ 找回之前的版本，把它複製回 public/data/poems.json。
